# 2026-11-21 - Project definition

**Goal for today:** close the initial decisions and write the specification.

**What I did:**
- Defined the measurable requirements (document in docs/).
- Installed Fusion for CAD design.

**Decisions and why:**
- Tethered link instead of radio: radio does not penetrate water, and a
  tether allows depth control, video and telemetry.
- Design depth 3 m (the deep end of the pool is ~2.5 m): a cheap safety
  margin, since the pressure is only ~0.3 bar.
- 110 mm PVC pipe and 3D-printed fairing: the cheapest option.
