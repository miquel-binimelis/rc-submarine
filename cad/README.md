# CAD files

STEP exports of the Fusion model. A new version number (v0, v1, ...) is used whenever the geometry changes.

| File | Description |
|---|---|
| `hull_tube_v0.step` | Pressure hull: PVC sanitary pipe, Ø110 mm, 3.2 mm wall, 600 mm long. |
| `end_cap_v0.step` | End cap with two radial O-ring grooves and a flange. |
| `end_cap_v1.step` | End cap with the flange reduced to Ø108 mm so it clears the fairing. |
| `hull_assembly_v0.step` | Hull tube with both end caps. |
| `packaging_study_v0.step` | Internal packaging study: ballast, battery, ESP32 and motor-driver blocks inside the hull. |
| `fairing_v0.step` | Free-flooding nose fairing (118 mm elliptical nose + 40 mm sleeve, 2 mm wall); printed twice, bow and stern. |
| `hull_assembly_v1.step` | Full assembly: hull tube, end caps v1, ballast, internal blocks and both fairings. |
