# RC Submarine (tethered)

Solo extracurricular project: design and build, from scratch, a ~1 m
tethered RC submarine, working by June 2027.

**Status:** Phase 1 - concept design (hull tube and end caps modelled).

## Goals
- Watertight hull, rated for 3 m, operated down to the bottom of a 2.5 m pool
- Controlled with a gamepad over a tether
- Depth and heading hold (PID) as a target

## Repository contents
- `docs/` - specification, decision records, test reports
- `docs/engineering-log/` - engineering log, one entry per work session
